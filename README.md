# Hospital Admissions Forecasting: Autoregressive Stochastic Models

Stochastic Operations course project, B.E. Industrial Engineering, Lebanese
American University

## Overview
A time series forecasting project in a healthcare setting. The team built an
autoregressive simulation model to predict future values of daily hospital
admissions, supporting better resource allocation decisions.

## What I did
- **Model development:** partnered with teammates to develop an autoregressive
  simulation model for predicting future values of a healthcare time series
- **Data analysis:** analyzed historical hospital admission data using
  autoregressive stochastic models
- **Forecasting:** wrote MATLAB code to predict daily admissions, enabling
  optimal resource allocation strategies

## Methods
- Autoregressive (AR) models
- Stochastic simulation
